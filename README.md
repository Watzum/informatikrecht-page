# Let Comedy Thrive

Mehrseiten-Webseite für die Plattform Let Comedy Thrive.

## Projektfokus

- Unternehmensdarstellung von Let Comedy Thrive
- Streaming- und VOD-Plattform
- Schwerpunkt auf klarer Informationsstruktur und Barrierefreiheit

## Technik

- React + Vite + TypeScript
- Clientseitiges Routing mit React Router
- Keine Backend-Anbindung, keine echte Authentifizierung, keine echten Zahlungen

## Starten

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## WCAG-Umsetzung (2.2 AA)

- Tastaturbedienbarkeit und sichtbare Fokusindikatoren
- Semantische HTML-Struktur und Landmarken
- Skip-Link zum Hauptinhalt
- Kontraststarkes Farbsystem
- Responsive Layout für Smartphone, Tablet und Desktop

Die Barrierefreiheitserklärung ist über die Navigation und den Footer erreichbar.
